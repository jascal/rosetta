# Independent confirmation of the open 32-token/two-source circuit

Status: **open**, before new context construction or full-context references.
This is a separate fixed-hypothesis trial, not a declaration that the rejected
911/912 study passed its admission gates.

The open candidate is **exactly option 5**: minimum match 32, support 2,
four-token source-length margin, and strict agreement with the frozen
categorical prior. It has a clean finite development certificate on 54 cases,
but no train incremental coverage and only one train causal group. Those facts
remain part of the record. No parameter, band width or normalization rule is
changed in this trial. No alternative candidate may replace it after answers.

## A defined guard population, not a uniform coverage estimate

The previous raw-role matrix did not exercise this candidate's incremental
train domain. This trial therefore samples the existing guard's lexical
precondition **before** any full-context answer is known. It does not narrow or
change the deployed rule. It measures faithfulness on designed guard-relevant
inputs, not unbiased natural-language coverage.

Seeds **921/922**, three groups per length, instantiate the complete 612-case
matrix: lengths 32/48/64, prefixes 16/24/32, two/three sources, 12/16-token
decoys, both source orders, zero/eight-token gaps, paired all-source target edits
and independent no-repeat/tied-source controls. Retain all controls and
abstentions. Groups and actual context vocabularies exclude all earlier full
contexts and are disjoint between the two trial seeds.

For each planned group, draw six unused query candidates, twelve unused target
candidates and six unused decoy candidates from the original frozen role pools.
Assign random ranks before consulting any feature. Datalog chooses the first
ranked tuple with two distinct target candidates whose prior bands are both
strictly better than the decoy's. No full-context reference, native explanation,
token string or previous success label may enter this choice. A group with no
eligible tuple aborts construction; do not resample to rescue it. Candidate
blocks are disjoint across groups, preventing selected-token overlap.

Background tokens are drawn uniformly from the frozen background pool excluding
every previously occurring context token. Previously reserved tokens that never
occurred in a context may be used; this is checked by actual token membership,
not an answer-dependent exclusion. Only the background tokens needed for the
declared layout are allocated. No feature value affects background selection.

The intrinsic lexical module was frozen before all these contexts; it already
contains the alphabet, so this is fresh composition/context evidence rather
than a claim of an unseen feature alphabet. The fixed tuple constructor is an
explicit semantic-type condition. Its coverage figures must not be presented
as comparable to the earlier unconditional raw-role sample.

## Freeze and pass gates

Before any trial model request, emit option 5 plus the metadata-only lexical
specialization, verify required features, and freeze exact artifact bytes,
contexts, paired edits, exclusions, tuple-choice evidence, firing/incremental
domains and predictions, source hashes and oracle identity.

Require all of the following:

- Every trial reference is present, unique and in-domain.
- `dl/equiv.dl` passes on the complete nonempty firing and incremental domains:
  no mismatches, uncovered, missing-reference or invalid obligations.
- Incremental coverage is positive for each trial seed relative to the unchanged
  behavior-only baseline. Active successful target-substitution pairs occur in
  at least two independent groups for each seed.
- Full-trial certificates retain abstentions as uncovered obligations. Report
  all baseline overlap, conflicts, errors and baseline-only cases.
- The relocated artifact runs with token/domain facts and Souffle alone, with
  identical decisions and abstentions to the frozen reference-free query.
- All retained queries replay model-free with exact relations and verdicts;
  frozen hashes and the complete lexical module remain unchanged.

This circuit is the standalone candidate; the baseline is a comparison, not an
uncertified runtime fallback. Any wrong firing answer fails this fixed trial.
Do not remove cases, change a guard, substitute option 6, or reinterpret a
successful subset as confirmation. Retain and report failure if a gate fails.

Success proves only the stated finite domains relative to the pinned oracle,
with empirical coverage on this designed population. It does not prove
whole-model replacement, arbitrary-input faithfulness or anatomical sufficiency.
